# Publicador Videos

Web pública de la herramienta personal que publica los vídeos de @unporquecadadia, @radarmeta y @gym_conciencia
en Instagram, TikTok y YouTube. Contiene la página de inicio, la política de privacidad y las condiciones, en
español (raíz) y en inglés (`en/`). La sirven GitHub Pages: https://radarmetaofficial.github.io/

- Los textos están en `build.py`; `python build.py` regenera los HTML.
- Sin cookies, analítica ni recursos de terceros. Fuentes Space Grotesk y JetBrains Mono (SIL OFL 1.1, licencias en `fonts/`).
- Las imágenes y el clip son fotogramas y logos propios de las tres marcas.
