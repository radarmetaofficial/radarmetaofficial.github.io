Quién la usa y quién responde

Publicador Videos es una herramienta personal. La usa una sola persona, el titular de las cuentas @unporquecadadia, @radarmeta / @radar.meta, @gym_conciencia / @gym.conciencia (en adelante, «el responsable»), para publicar sus propios vídeos en sus propias cuentas. No se ofrece a terceros y no admite usuarios externos.

Contacto del responsable: radarmeta.official@gmail.com.

Qué datos trata

RedDatosPara qué

Además se envían a cada red el vídeo y su descripción, que son contenido propio del responsable. La herramienta no lee seguidores, mensajes, comentarios ni estadísticas, y no trata datos de ninguna otra persona.

Dónde se guardan y cuánto tiempo

  • Todo se guarda únicamente en el ordenador del responsable, en una carpeta de su perfil de usuario fuera de cualquier proyecto o repositorio. No hay servidor, base de datos en internet ni copia en la nube.
  • Instagram: la llave dura 60 días y se renueva automáticamente cada semana mientras se use.
  • TikTok: la llave dura 24 horas y la de renovación, alrededor de un año.
  • YouTube: la llave se conserva hasta que se retire el permiso.
  • Un registro local anota la fecha de cada renovación y si fue correcta; no contiene las llaves.
  • Al retirar el permiso o dejar de usar la herramienta, los archivos se borran.

Con quién se comparten

Con nadie más que la propia red: cada dato se envía solo a la plataforma a la que pertenece (Meta, TikTok o Google) y solo para publicar en la cuenta correspondiente. No se venden, no se ceden, no se usan para publicidad y no se transfieren a otros servicios.

Cómo retirar el permiso

  • Instagram: Configuración → Aplicaciones y sitios web → Activas → Publicador Videos-IG → Eliminar.
  • TikTok: Perfil → Ajustes y privacidad → Seguridad y permisos → Aplicaciones y servicios → Publicador Videos → Eliminar acceso.
  • YouTube / Google: en la página de permisos de tu cuenta de Google, myaccount.google.com/connections (o security.google.com/settings/security/permissions), elige Publicador Videos y quita el acceso.

También puedes pedir que se borren los datos escribiendo al contacto de arriba; se hará en un plazo máximo de 30 días.

Normas de cada plataforma

Publicador Videos usa los Servicios API de YouTube. Al usarla se aplican las Condiciones de servicio de YouTube y la Política de privacidad de Google.

También se aplican las Condiciones de servicio y la Política de privacidad de TikTok, y las Condiciones de uso de Instagram y la Política de privacidad de Meta.

Esta web

Esta página no usa cookies, ni analítica, ni rastreo, ni fuentes, vídeos o scripts de terceros: todo se sirve desde aquí mismo. El alojamiento (GitHub Pages) puede registrar datos técnicos de las visitas, como la dirección IP, según la declaración de privacidad de GitHub.

Tus derechos

Si crees que la herramienta trata algún dato tuyo, puedes pedir acceso, rectificación o supresión escribiendo a radarmeta.official@gmail.com. También puedes reclamar ante la Agencia Española de Protección de Datos (aepd.es).

La herramienta no está dirigida a menores y no recoge datos de menores.

Cambios

Si cambia lo que trata la herramienta (por ejemplo, si algún día publica directamente en TikTok), esta página se actualizará y cambiará la fecha de arriba antes de que el cambio se aplique.
